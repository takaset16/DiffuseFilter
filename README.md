# DiffuseFilter

Official implementation of "DiffuseFilter: Efficient Data Augmentation Using Filter Images Generated by Diffusion Models".

DiffuseFilter generates a small, dataset-independent set of filter images with Stable Diffusion once,
and composites them onto training images on the fly. The low-frequency components of a filter image are
transferred to the training image by low-frequency replacement (LFR), the result is joined with the original
image by a soft mask, and a fractal image is blended in.

## Setup

```bash
pip install -r requirements.txt
```

Tested with Python 3.9 and PyTorch 2.x on a single GPU.

## Data

```
data/
  CUB_200_2011/        # images/, images.txt, image_class_labels.txt, train_test_split.txt, classes.txt
  stanford_cars/       # torchvision.datasets.StanfordCars layout
  fgvc-aircraft-2013b/ # torchvision.datasets.FGVCAircraft layout
  flowers-102/         # torchvision.datasets.Flowers102 layout
  cifar-100-python/    # torchvision.datasets.CIFAR100 layout (upscaled to 224x224 like the other datasets)
filters/               # 180 filter images (9 styles x 20), included in this repository
fractals/              # fractal images from the DiffuseMix fractal dataset
```

- **Filters**: `filters/` contains the 180 images used in the paper (9 styles x 20, generated once with
  Stable Diffusion v1.5 at 512x512). Files are named `background_<style>_<i>.png`.
- **Fractals**: download the fractal dataset provided by [DiffuseMix](https://github.com/khawar-islam/diffuseMix)
  and put the images in `fractals/`.

## Training

DiffuseFilter (ResNet-18, CUB):

```bash
python train.py --dataset CUB --model ResNet18 --diffusefilter 1 --seed 0
```

Standard data augmentation only (resize 256, random crop 224, horizontal flip):

```bash
python train.py --dataset CUB --model ResNet18 --seed 0
```

Main options (defaults in parentheses):

| Option | Meaning |
|---|---|
| `--dataset` | `CUB`, `StanfordCars`, `FGVCAircraft`, `Flowers102`, `CIFAR100` |
| `--model` | `ResNet18`, `ResNet50`, `ViT_B16` (ImageNet-pretrained) |
| `--alpha` (0.4), `--radius` (16) | LFR strength and mask radius |
| `--apply_ratio` (0.5) | fraction of each batch that is augmented |
| `--blend_width` (32) | width of the soft mask boundary in pixels |
| `--fractal_alpha` (0.05) | blending weight of the fractal image |

Each run writes a JSON file to `--out_dir` with the final-epoch accuracy (`acc_final`), the accuracy curve,
the training time per epoch and the peak GPU memory.

Defaults follow the paper: ImageNet-pretrained backbone, SGD (momentum 0.9, Nesterov), learning rate 0.001,
weight decay 5e-4, batch size 32, 100 epochs, 3-epoch warm-up followed by cosine decay, 5 seeds (`--seed 0..4`).
The reported metric is the final-epoch test accuracy.

### Hyperparameter selection

`--val_mode holdout` trains on part of the training set and reports accuracy on a held-out validation split
(official val split for Aircraft and Flowers, a stratified 10% for CUB and Cars). The test set is not used.

```bash
python train.py --dataset CUB --diffusefilter 1 --radius 8 --alpha 0.6 --val_mode holdout
```

### Ablations

| Experiment | Options |
|---|---|
| Without the mask concatenation / filter / fractal | `--use_concat 0`, `--use_filter 0`, `--use_fractal 0` |
| Mask shape, amplitude normalization | `--mask_shape {circle,square,gaussian}`, `--amp_norm 0` |
| Composite operator | `--composite {lfr,fda,pixel,reinhard,colorjitter}`. FDA: `--composite fda --mask_shape square --amp_norm 0`; FDA with the LFR mask: `--composite fda`; APR: `--composite fda --radius 10000 --mask_shape square --amp_norm 0`; pixel blend: `--composite pixel --alpha 0.3` |
| Fractal blending weight of DiffuseMix | `--fractal_alpha 0.2` |
| Filter source | `--filter_dir <dir>`; control sets are made with `scripts/make_control_filters.py` (`powerlaw`, `phase_rand`, `random_smooth`, `solid`, `natural`) |
| Number of filters, prompts | `--filters_per_style N`, `--filter_styles snowy,aurora` |

### Comparison methods

```bash
python train.py --dataset CUB --baseline cutmix
python train.py --dataset CUB --diffusefilter 1 --baseline snapmix   # combination
```

`--baseline` accepts `mixup`, `cutmix`, `cutout`, `color_jitter`, `saliency_mix`, `puzzle_mix`, `co_mixup`,
`snapmix`, `guided_mixup`, `patch_gaussian`, `random_crop`, `rotate`, `shear_x`, `shear_y`, `vertical_flip`.
Their parameters are set with `--da_param1/2/3` (see `DEFAULT_PARAMS` in `diffusefilter/baselines.py`).
By default, `rotate` rotates each image by an angle in U(-30, 30) degrees, and `patch_gaussian` adds Gaussian noise
with sigma ~ U(0, 1) to a 112x112 patch of each image in [0, 1] space.
SaliencyMix, PuzzleMix, Co-Mixup, SnapMix and GuidedMixup are simplified re-implementations that use
spectral-residual saliency instead of CAM or gradient saliency.

### DiffuseMix

Generate images with the [official DiffuseMix code](https://github.com/khawar-islam/diffuseMix) into
`diffusemix/<dataset>_augmented/<class name>/`, then:

```bash
# original + generated images (9 generated images per original), 10 epochs (same number of steps as 100 epochs on the original data)
python train.py --dataset CUB --diffusemix combine --dm_max_k 0 --epochs 10
# generated images only, 11 epochs
python train.py --dataset CUB --diffusemix only --dm_max_k 0 --epochs 11
```

`scripts/check_lfr_equivalence.py` checks numerically that LFR equals `x + alpha (L s - L x)` in the spatial
domain, where `L` is an ideal low-pass filter.
